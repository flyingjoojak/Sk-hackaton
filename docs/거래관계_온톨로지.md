# 거래관계 온톨로지

6시간 안에 쓰는 최소 스키마다. 저장은 CSV 와 메모리 `dict`. networkx 가 있으면 같은 간선으로 그래프를 한 번 더 만들고 차수 중심성만 대조한다. Neo4j 는 설치하지 않는다. 아래 Cypher 는 스키마를 설명하는 예시일 뿐이다.

## 노드

| 타입 | 필수 속성 | 있으면 쓰는 속성 | 6시간 메모 |
|---|---|---|---|
| Company | company_id, name | country, industry | id 가 키. 이름 병합은 분석 전에 한다 |
| Product | product (이름 또는 코드) | category | 부품·자재·제품 구분 열이 없으면 한 종류로 둔다 |
| Industry | industry | | Company 의 속성으로 충분. 노드로 나누지 않아도 된다 |
| Location | country | region | Company.country. 빈 값은 추정하지 않는다 |
| RiskEvent | type, target | as_of | 부도, 수출통제, 단가 상한. 조건 JSON 으로 표현 |
| Financials | company_id, period | revenue, operating_income, equity | 별도 CSV. 없으면 재무 규칙은 안 함 |

## 간선

| 타입 | 방향 | 속성 | 의미 |
|---|---|---|---|
| SUPPLIES | supplier → buyer | product, amount, qty, period | 기간 안 공급. amount 는 구매 금액. qty 가 없으면 단가를 계산하지 않는다 |
| OWNS | parent → subsidiary | share | 지분. 데이터가 없으면 만들지 않는다. 공급 전파와 섞지 않는다 |

같은 (buyer, supplier, product, period) 가 여러 줄이면 금액을 더한다. amount 가 0 이거나 음수면 그 행은 제외하고 건수를 센다. 자기 자신으로의 공급은 오류 목록에 넣고 간선에서 뺀다.

## 메모리 구조

```
companies[id] = {name, country, industry}
edges = [(supplier_id, buyer_id, product, amount, period), ...]
out_edges[supplier_id] = [(buyer_id, product, amount, period), ...]
```

입력 리스트는 고치지 않는다. 합산본은 새 리스트로 만든다.

networkx 가 있을 때:

```python
import networkx as nx
g = nx.DiGraph()
for s, b, product, amount, period in edges:
    g.add_edge(s, b, product=product, amount=amount, period=period)
```

없는 환경에서도 같은 분석이 끝나야 한다. 중심성 기본값은 차수(출·입)를 n-1 로 나눈 값이다.

## 자주 쓰는 조회

- 한 구매자의 자재별 공급처와 금액 비중
- 한 공급자가 멈추면 아래로 닿는 구매자 (BFS, 깊이 상한)
- 자재를 공급하는 기업 목록 (대체처 후보)
- 국가가 같은 기업 집합

비중은 금액 합이 0이면 계산하지 않고 사유를 남긴다. HHI = Σ (금액_i / 합)^2. 독점 1, 완전 분산에 가까울수록 작다.

## Cypher 예시 (실행하지 않음)

```cypher
CREATE (:Company {id: 'B', name: '가짜소재', country: 'ZZ'});
MATCH (s:Company {id: 'B'}), (b:Company {id: 'A'})
CREATE (s)-[:SUPPLIES {product: 'wafer', amount: 80, period: '2026'}]->(b);

MATCH (s:Company {country: 'ZZ'})-[r:SUPPLIES]->(b)
RETURN b.id, sum(r.amount) AS lost;
```

당일 제출물은 이 쿼리를 돌리지 않아도 된다. 심사자에게 "그래프 DB 로 옮기면 간선 타입이 이렇게 간다"고 말할 때만 쓴다.

## 하지 않는 것

- 기사 본문, 공시 PDF 를 노드로 자동 수집
- 임베딩으로 회사 유사도
- 지분과 공급을 한 경로로 이어서 위험 금액을 합산 (단위가 다르다)
- 이름만 보고 id 를 자동 병합 (후보는 보여 주고, 병합은 사람이 고른 뒤에만)
